## Учебные проекты

### [Склад пищевого производства](https://github.com/royalistofficial/course-work-on-databases)
Курсовая работа по базам данных — веб-приложение на Django. Реляционная БД из 14 таблиц: склады, продукция со сроками годности, рецепты, цеха, поставщики, заказы. Формы для добавления, редактирования и удаления данных с валидацией; отчёты за период по списаниям и по чекам поставщиков и покупателей.
<br>**Стек:** `Python` · `Django` · `Django ORM` · `SQLite` · `HTML/CSS`

### [Python: от основ до машинного обучения](https://github.com/royalistofficial/CK24-Python-Basics-to-ML)
Домашние задания курса ЦК24:
- **сжатие матрицы весов** — квантизация, кодирование Хаффмана, упаковка в бинарный файл и восстановление, на чистом Python без NumPy;
- **парное выравнивание последовательностей** — алгоритм Нидлмана–Вунша с матрицей BLOSUM;
- **символьное дифференцирование** — классы выражений с вычислением и взятием производных;
- **пайплайн задач** — запуск шагов по графу зависимостей.

<br>**Стек:** `Python` · `Jupyter` · `ООП`

### [Алгоритмы и структуры данных на C](https://github.com/royalistofficial/algds2024)
Лабораторные работы: вставка и удаление в красно-чёрном дереве без ссылок на родителя; путь с минимальным штрафом в матрице методом динамического программирования.
<br>**Стек:** `C` · `CMake`

### [Huffman Coding](https://github.com/royalistofficial/HuffmanCoding)
Консольная утилита для сжатия и распаковки файлов алгоритмом Хаффмана с параметрами командной строки (`-i`, `-o`, `-d`).
<br>**Стек:** `Java`
